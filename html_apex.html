How this works: CSS selectors are rescoped under the root id (body → #root, bare classes get #root prefixed, @keyframes is left untouched). Inline-handler functions get namespaced and exposed on window; helper functions only used internally stay as plain declarations inside the wrapping IIFE. Function detection tolerates normal indentation but is still line-based, not a real parser — it can occasionally pick up a shallow nested function, and won't see anything defined inside a single-line or minified script. This is a best-effort, regex-based rewrite — always review the output.
